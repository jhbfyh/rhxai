# 项目总览

## 一、项目定位

| 项 | 内容 |
| --- | --- |
| 站名 | 永远在线的"搭子" |
| 体裁 | 滚动叙事型数据报道（scrollytelling + 交互图表） |
| 主题 | 未成年人使用 AI 情感陪伴产品的现状、机制、伤害与治理 |
| 读者路径 | 序言问卷代入 → 规模与历史 → 心理机制 → 真实伤害 → 治理与素养 |
| 语言 | 简体中文 |
| 交付形态 | 纯静态站点，1 个首页 + 5 个章节页 + 共享 CSS/JS，第三方依赖全部本地化 |

## 二、技术形态

- **无构建系统**：没有 package.json、打包器或预处理器。HTML 内的 `<style>` 与 `<script>` 直接内联，双击即可打开。
- **无框架**：不依赖 React / Vue，DOM 操作与动画全部原生实现。
- **图表**：ECharts 5.4.3 承担柱线图、旭日图、玫瑰图等；`01-online.html` 额外用 ECharts-GL 2.0.9 做 3D 地球仪；`index.html` 用 ECharts 中国地图 + D3 7.9.0 做粒子布局。
- **自绘动画**：`crowd.js` 用 Canvas 2D 绘制人群；`02-cocoon.html` 的心电图、弹幕、`04-breaking.html` 的辩论与地图用原生 Canvas/SVG/CSS 实现。
- **响应式**：靠 CSS `clamp()` 字号刻度与各页 `@media` 断点（各页 2–16 处，主断点 640px / 900px 量级）。
- **无障碍与降级**：`common.js` 提供 `matchReduce()`，各页动画对 `prefers-reduced-motion` 做降级；图表初始化前均判断 `typeof echarts === 'undefined'`。

## 八、复用与参考

- 复用项目内已有实现：色板统一走 `theme.css` 的 12 个 token；进场动画与数字滚动统一走 `common.js`；人群绘制统一走 `crowd.js` 的 `CrowdField`；核心数据统一走 `window.DATA`。
- 参考的公开实现：图表配置遵循 ECharts 官方 option 结构；3D 地球仪使用 ECharts-GL `globe` 系列官方示例的贴图 + `viewControl` 相机控制方式。
