## 二、目录职责

| 目录 | 放什么 | 不放什么 |
| --- | --- | --- |
| 根目录 | `index.html`、`_headers`、`README.md` | 章节页、脚本 |
| `chapters/` | 01–05 章节 HTML | 首页、图片 |
| `components/` | 公共 JS | 页面内联脚本 |
| `data/` | 数据层 | 图表配置 |
| `styles/` | 主题 token 与导航样式 | 页面内联样式 |
| `vendor/` | 第三方库与 GeoJSON 本地副本 | 自研代码 |
| `assets/` | 页面实际引用到的图片与视频 | 原始大图、未被引用的素材 |
| `deliverables/` | 对外交付的成图 | 中间稿、草稿 |
| `archive/originals/` | 压缩前的原始文件 | 站点直接引用的成品 |
| `archive/unused/` | 有保留价值但当前未引用的成品 | 可再生的临时文件 |
| `archive/previews/` | 独立预览页、检查截图 | 正式章节页 |
| `tools/` | 可重复执行的一次性脚本 | 运行时依赖 |
| `docs/` | 本套说明文档 | 代码、素材 |

## 三、路径规则

### 3.1 章节页引用资源

章节页位于 `chapters/`，资源在根目录 `assets/`，相对路径固定为两级：

```
../assets/images/covers/cover-ch1-partner.webp
../assets/videos/opening-cover.mp4
```

首页 `index.html` 在根目录，直接写：

```
assets/images/...
assets/videos/...
```

### 3.2 章节页引用共享代码

```
../styles/theme.css
../components/common.js
../components/crowd.js
../components/people-sprites.js
../data/data.js
../vendor/echarts.min.js
../vendor/echarts-gl.min.js
../vendor/geo/world.json
```

首页对应为 `styles/theme.css`、`components/...`、`data/...`、`vendor/...`（无 `../`）。

### 3.3 页面之间互链

章节页之间同目录，直接写文件名；指向首页需回到上一级：

```
chapters/01-online.html          →  chapters/02-cocoon.html
chapters/05-backmatter.html      →  ../index.html
index.html                       →  chapters/01-online.html
```

### 3.4 CSS 内的图片引用

`background:var(--cover-deep) url("../assets/images/covers/cover-ch2-cocoon.webp")`——CSS 写在章节页内联 `<style>` 中，按章节页位置解析，用 `../`。

## 四、移动或改名时的连带影响

| 操作 | 需要同步修改 |
| --- | --- |
| 移动 `chapters/` 或 `assets/` 任一目录 | 全部章节页中的 `../assets/...` 与 `../styles|components|data|vendor/...` 路径，以及首页的同类路径 |
| 重命名章节文件 | 6 个页面顶部的 `site-nav` 链接 + 上一章的 `next-chapter` 链接 |
| 移动 `archive/previews/04-breaking-planA-demo.html` | 该页对 `../../assets/images/news/fig07-leftbehind-people-visual.webp` 与 `../../vendor/echarts.min.js` 的引用。当前 `archive/` 与 `assets/`、`vendor/` 同级，路径成立 |
| 新增图片 | 只放 `assets/` 对应子目录，原始大图另存 `archive/originals/` |
| 新增第三方库 | 放 `vendor/`，页面用相对路径引用，不加 CDN |
