## 页面通用结构

每个章节页遵循同一骨架：

```
<nav class="site-nav">          顶部导航（品牌 + 5 个链接 + 进度条）
<section class="section"> ... 正文分节
<a class="next-chapter">        章末跳转卡（附录回到序言）
```

- 导航进度条由 `common.js` 计算 `scrollTop / (scrollHeight - clientHeight)`。
- 章末跳转卡带 `data-next` 属性，由 `common.js` 的 IntersectionObserver 控制进场。
- 所有章节页内联样式均以 `theme.css` 的 token 为唯一色源，页面内不重复声明色板。
