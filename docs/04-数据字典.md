# 数据字典

数据层文件：`data/data.js`，以 `<script>` 方式定义 `window.DATA`，共 5 个顶层键，210 行。

引用页：`index.html`、`01-online.html`、`02-cocoon.html`、`04-breaking.html`。`03-wound.html` 未引入该文件，数据写在内联脚本与 HTML 中。

```
window.DATA
├── intro   序言：样本构成、四题答案、认知落差、调研省份

├── ch2     第二章：茧三层旭日图、Zeta 三条序列

```

### sunburst 三层结构

| 层 | 名称 | 子项 | 颜色 |
| --- | --- | --- | --- |
| 最外层 | 永不疲倦的回应 | 即时回应、无条件接纳、零拒绝交互 | `#3A6B8A`（step-1） |
| 中层 | 量身定制的迎合 | 记住偏好、顺着情绪 | `#F4C95D`（gold），标签用深色 `#1A3A4A` |
| 最内层 | 越来越深的自我暴露 | 越说越深、离不开它 | `#B84A3E`（risk） |

颜色直接内嵌在数据节点 `itemStyle.color` 中，与 `theme.css` 的 token 值一致。
